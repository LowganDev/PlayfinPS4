# Playfin 2.0

## Intent

Another PS4 Jellyfin client (JellyFin [PS] for PS4, v1.12, 2026-10-28) offers features Playfin 1.0 lacks and is
downloaded more. 2.0 gives Playfin every one of those features, keeps what only Playfin has (14 languages,
several servers and users, verified HTTPS with pinning, recordings, styled CJK subtitles, accent colour, tests and
security review), and adds the next-episode card the user asked for.

## Decisions (the user's, 2026-11-07)

- **Next episode:** a card in the last 10 s of an episode that has a next one: its picture, "Épisode suivant",
  its number and title, "Dans N s". ✕ plays it now, ◯ cancels the card (the episode ends and the player closes).
  When the countdown ends the next episode plays by itself. It replaces the "Épisode suivant" button of the last
  30 s and the countdown after the end.
- **Offline downloads** on the console only, in `/data/Playfin/downloads`.
- **Software update** downloads the newer package to `/data/pkg` (the one write outside `/data/Playfin`, approved
  for that file only), checked against its published size and SHA-256; the user installs it from GoldHEN.
- **Per-PS4-user profiles** (each console user gets back their own Jellyfin user; a sign-in can be shared with
  console users who have none) and a **screensaver**. No light bar colour.
- Work on branch `2.0`; nothing is published before the user tries it on the console.

## Features (what the other client has and Playfin lacks)

1. Player: volume (remembered), picture size (Fit / Fill / Stretch, zoom), L2 / R2 ±5 min, "Se termine à" in the
   bar.
2. Details: cast and crew with photos (a person opens their filmography), director, "Se termine à", quality chips
   (resolution, HDR, audio channels), the community rating.
3. Libraries: an A–Z jump bar, a quick peek (△: synopsis, rating, cast), placeholder shimmer while pictures load.
4. Home: clock and date in the header; the order of "Mes médias" chosen in the settings; touchpad refreshes.
5. Search: results filtered by kind (L2 / R2).
6. Music: Genres and Songs tabs; a visualizer on Now playing; the volume.
7. Live TV: favourite channels, categories, recently watched, channel search.
8. Downloads: films, episodes, whole seasons, played offline; a Downloads screen.
9. Software update in the settings (and checked at start). — moved to 2.1 on 2026-11-08 (no Internet to test it on the console); kept on branch `2.1`.
10. Screensaver after a few idle minutes: Home's artwork, title and synopsis.
11. Per-PS4-user profiles and a shared sign-in.
12. README: screenshots made with free artwork, badges, the download button.

## Constraints

Playfin's rules: C++17 (OpenOrbis clang 12), `-Werror`, no `std::filesystem`, writes through `core::dataPath()`
(plus the `/data/pkg` exception above), tests first, Linux before the console, French UI in "vous", 14 languages,
no warnings the user did not ask for, never copy code from Switchfin, borealis, Playtube or the other client.
